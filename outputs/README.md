# yiyi 的风格作品集

## font/ —— Yiyi 手写体
`YiyiHand-Regular.ttf`（可直接安装）、`.woff2`（网页用）、`specimen.png`（样张）、`charset_hanzi.txt`（收录汉字表）。

| 内容 | 数量 | 来源 |
|---|---|---|
| 汉字 | 458 字，235 个额外变体 | 全部来自她的书写，逐格转录后提取 |
| 数字 0–9 | 每个 2 种写法 | 她的手写（数学口算页） |
| 英文 7 个字母 d h k n y S B | | 直接提取她的笔迹 |
| 英文 20 个字母 a b c e f g i l m o p r s t u w H A C E | | 字母压在印刷线上，照着她的笔迹描线 |
| 英文 26 个字母 j q v x z 及其余 21 个大写 | | 样本里没有，按她的笔法补画 |
| 标点、运算符号 | | 按她的笔法绘制 |

已排除：书本印刷体、红笔批改、圈画改字、涂黑格、页边批语、划掉的字。
同一字连续出现时会在 2–3 种写法间轮换（OpenType `calt`，需要软件支持，Word、Pages、浏览器等可用）。

**覆盖范围有限**：458 字只覆盖常用字表（GB2312 一级 3755 字）的约 12%，其他字会缺字，需要回退到别的字体。

## emoji/ —— 24 个纸片 emoji
`png/`（512×512 透明底）、`svg/`（矢量）、`overview.png`。原创绘制，不是她画作的拷贝。
提炼的风格：黑色细勾线、微抖出头的线条、歪斜摆放、点/短线/网格纹理、只用一支蓝笔点缀、剪刀剪出的折线白边、超大圆眼加外斜瞳孔、睫毛短线、X 形剪口、小短线辫子。

## stickers/ —— 16 张黏土表情包
`png/`（512×512）、`gif/`（240×240 动图）、`overview.png`。用 3D 建模重建她的四个黏土角色，配文取自她的作文词句，用 Yiyi 手写体书写。
提炼的风格：超轻黏土的哑光细绒、球形身体、小短肢、刻线翅膀、小蝴蝶结、豆豆眼、淡腮红。
粉团兔原作没有脸，五官是为了做表情加上的。

第 13–16 张的角色是她捏的皮卡丘同人形象，属于他人版权角色，私下使用没问题，不建议上架表情商店。

## source/
生成脚本、逐格转录（`labels.py`）和手动修正规则（`override.json`）。
